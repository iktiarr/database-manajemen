saya ingin menggunakan desain dari shadcn ui pada sistem ini agar terlihat rapi dan bersih

install skill yang dimiliki dulu "npx skills add shadcn/ui" agar kamu tau seperti apa desainnya

npx shadcn@latest add accordion, gunakan untuk memberikan beberapa informasi yang ada
npx shadcn@latest add alert, gunakan untuk memberikan informasi pesan apakah sudah berhasil atau tidak
npx shadcn@latest add alert-dialog, gunakan untuk memberikan konfirmasi
npx shadcn@latest add avatar, gunakan untuk memberikan informasi pengguna, cukup gunakan inisial nama nya saja agar lebih ringkas atau gunakan ikon wajah
npx shadcn@latest add badge, digunakan untuk memberikan informasi berupa badge
npx shadcn@latest add button, gunakan untuk desain tombol agar konsisten
npx shadcn@latest add button-group, gunakan untuk memberikan desain apabila ada beberapa tombol sekaligus
npx shadcn@latest add card, gunakan untuk form agar bagus
npx shadcn@latest add chart, gunakan untuk menampilkan data dalam bentuk diagram
npx shadcn@latest add checkbox, gunakan untuk memilih beberapa opsi, jika diisi berarti aktif dan sebaliknya
npx shadcn@latest add combobox, gunakan ini untuk tampilan yang ada dropdownnya
npx shadcn@latest add table --> npm install @tanstack/react-table, gunakan untuk memberikan desain tabel yang lebih lengkap
npx shadcn@latest add dialog, gunakan ini untuk menampilkan form untuk tambah sebuah data
npx shadcn@latest add field, gunakan ini juga sebagai pengganti form
npx shadcn@latest add hover-card, gunakan untuk melihat isi secara cepat tanpa membukanya
npx shadcn@latest add input, gunakan untuk input key atau yang lainnya
npx shadcn@latest add input-otp, gunakan untuk mengisi kode otp atau semacamnya
npx shadcn@latest add marker, gunakan sebagai pemisah
npx shadcn@latest add popover, gunakan untuk bagian edit langsung, bisa pengganti dialog
npx shadcn@latest add progress, menampilkan waktu kapan dari sebuah proses
npx shadcn@latest add radio-group, gunakan ketika memilih satu dari sedikit pilihan
npx shadcn@latest add scroll-area, gunakan untuk menampilkan beberap bagian tanpa scroll halaman penuh
npx shadcn@latest add select, gunakan untuk memilih beberap opsi, bisa sebagai pengganti pemilihan opsi
npx shadcn@latest add separator, gunakan sebagai pemisah pada setiap item
npx shadcn@latest add sidebar, gunakan untuk panel samping
npx shadcn@latest add skeleton, gunakan untuk animasi load loading lebih bagus
npx shadcn@latest add spinner, gunakan sebagai loading juga pada beberapa item
npx shadcn@latest add switch, gunakan untuk hanya 2 opsi
npx shadcn@latest add table, gunakan desain untuk tabel penuh pada halaman 
npx shadcn@latest add tabs, gunakan untuk pindah bagian saja
npx shadcn@latest add toast, gunakan untuk menampilkan notifikasi
npx shadcn@latest add toggle, gunakan sebagai favorit saja
npx shadcn@latest add toggle-group, gunakan apabila ingin menetapkan beberapa opsi

semua di atas ini, gunakan pada sistem ini agar tampilannya bagus, bersih, clean, simpel dan tidak berantakan. pastikan desainnya harus mendukung responsive. pastikan juga tidak ada yang berlebihan
